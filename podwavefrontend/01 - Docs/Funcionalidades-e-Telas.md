# Funcionalidades e Telas — PodWave

Entidade principal: **Podcast**

## Ficha — Atividade Aula 02

| Dado | Seu valor |
|---|---|
| Nome do campo de busca da sua entidade principal (plural, camelCase) | `podcasts` |

| Funcionalidade típica | Tela equivalente | Vale para o projeto? |
|---|---|---|
| Landing / página inicial | `LandingView.vue` | Sim |
| Cadastro e autenticação | `auth/LoginView.vue`, `auth/RegisterView.vue` | Sim |
| Exploração do conteúdo por categoria (Feed) | `FeedView.vue` | Sim |
| Upload/criação do conteúdo principal | `UploadView.vue` | Sim |
| Detalhe de um item do conteúdo principal | `podcasts/PodcastDetailView.vue` | Sim |
| Edição de um item do conteúdo principal | `podcasts/EditPodcastView.vue` | Sim |
| "Meus itens" (conteúdo publicado pelo próprio usuário) | `podcasts/MyPodcastsView.vue` | Sim |
| Perfil próprio / perfil público | `profile/MyProfileView.vue`, `profile/PublicProfileView.vue` | Sim |
| Listas/favoritos personalizados | — | Não (fora do escopo inicial) |
| Busca | `SearchView.vue` | Sim |
| Notificações | `NotificationsView.vue` | Sim |
| Dashboard administrativo | `admin/AdminDashboardView.vue` | Sim |
| Denúncias / moderação | `admin/AdminReportsView.vue` | Sim |
| Gerenciamento de usuários (admin) | `admin/AdminUsersView.vue` | Sim |
| Gerenciamento do conteúdo principal (admin) | `admin/AdminPodcastsView.vue` | Sim |
| Rota não encontrada | `NotFoundView.vue` | Sim |
