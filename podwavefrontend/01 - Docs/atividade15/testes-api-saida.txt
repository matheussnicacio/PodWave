== 06. Bloquear
-- bloquear B:
{"success":true,"message":"Usuário bloqueado.","data":{"id":3,"username":"usuario_b","isBlocked":true}}
[HTTP 200]
-- repetir: 200
-- token ANTIGO de B em /profile/me:
{"success":false,"message":"Sua conta foi bloqueada. Entre em contato com a administração.","errors":[]}
[HTTP 401]
-- login de B com a senha certa:
{"success":false,"message":"Sua conta foi bloqueada. Entre em contato com a administração.","errors":[]}
[HTTP 403]
-- login de B com a senha errada:
{"success":false,"message":"E-mail ou senha inválidos.","errors":[]}
[HTTP 401]
-- perfil público de B (visitante): 200
-- desbloquear B:
{"success":true,"message":"Usuário desbloqueado.","data":{"id":3,"username":"usuario_b","isBlocked":false}}
[HTTP 200]
-- o MESMO token de B volta a funcionar: 200
-- erros: {} -> 400   "true" (texto) -> 400   a si mesmo -> 400
-- outro administrador (C promovido só para o teste) -> 403   99999 -> 404   abc -> 400
-- mensagens: Informe isBlocked (true ou false). | isBlocked deve ser um booleano (true ou false). | Você não pode bloquear a sua própria conta.
